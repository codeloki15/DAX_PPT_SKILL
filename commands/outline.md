Draft a storyline for: $ARGUMENTS

Use the `dax-ppt` skill's rules for action titles. Do not build any slides yet.

Produce a numbered list, one line per slide, in deck order:
- slide 1: **[cover]** the deck title, 8 words or fewer
- before each topic: **[topic]** the topic name, 2-7 words (a divider slide on the Data Axle light
  background tells the audience a new topic starts)
- each content slide: a kicker (section label, 1-3 words), then the action title (the finding, as a
  sentence of 16 words or fewer, no trailing period), then in brackets the exhibit that would prove it
  (chart type, exhibit type or table) and the data it needs

Then check the list the way a reader would: read only the content titles, top to bottom. Do they make one
argument? Is any title a topic label ("Revenue by region") rather than a finding? Rewrite until they do.

Flag every figure the titles depend on that the user has not supplied and no file provides - those
become em-dash placeholders, never estimates. End by asking the user to approve or edit the list.
